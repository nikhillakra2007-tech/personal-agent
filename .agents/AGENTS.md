# Workspace Agent Guidelines

## UI/UX Design Intelligence

- Use the installed skill at `.agents/skills/ui-ux-pro-max/`.
- Query design recommendations via `python .agents/skills/ui-ux-pro-max/scripts/search.py "<query>"`.
