### 🚀 Flagship Project: [Lakra 2.0 (Personal Agent)](https://github.com/nikhillakra2007-tech/personal-agent)

A local-first, single-user browser automation agent engineered with a strict **Control Plane vs. Execution Plane** separation and multi-tiered **L0–L4 policy enforcement**.

```
User Goal → Analyzer → Deterministic Planner → Policy Engine (L0–L4) → Scheduler → Router → Execution Plane → Multi-Phase Verifier → Append-Only Audit
```

- 🛡️ **Zero Guesswork / Refusal-First**: Ambiguous goals trigger hard refusal instead of hallucinated actions.
- 🚦 **L0–L4 Governance**: Read-only (L0), Reversible (L1), Bounded (L2), Human Approval Gates (L3), and Hard-Blocked Dangerous Operations (L4).
- 🔍 **Real World Verification**: Never equates *"click happened"* with *"task succeeded"* — enforces DOM state, link resolution, and element mutations.
- ⚡ **Cross-Process Token Approvals**: Out-of-band human-in-the-loop CLI for L3 action review with atomic token validation.
- 🧪 **Test Suite**: 546 unit, integration, and scenario tests with 30/30 V1 demo checks passing.
